# Hive Block Producer

以 Hive 區塊鏈為主題的網頁落塊遊戲，純前端，不需要安裝任何東西。

- 線上試玩：https://d-bot-2026.github.io/Claude/ （GitHub Pages，推送到預設分支後自動部署，設定見 `.github/workflows/pages.yml`）
- 本機開啟：直接用瀏覽器打開 `hive-block-producer/index.html`（同資料夾的 `i18n.js` 是翻譯檔，兩個檔案要放在一起）。
- 網頁設定了不讓搜尋引擎收錄，目前只有拿到網址的人會找到它；但網址本身是公開的，任何人都打得開。

首頁可以輸入暱稱、以訪客身分開始，並查看這台裝置的前 10 名紀錄。Hive 帳號登入與鏈上紀錄規劃中。

> 遊戲中的 HIVE、HBD、HP 與 RC 都只是遊戲點數，不是真實的加密貨幣，沒有任何價值，也無法提領或兌換。

## 玩法特色

- **錢包計分**：分數以 HIVE 計，保留小數點後 3 位，跟鏈上金額格式一樣。
- **HIVE / HBD 代幣**：有些方塊帶著代幣，清除該列可拿額外 HIVE；HBD 會存進儲蓄，每 20 個區塊派息 5%。
- **資源點數 RC**：保留方塊（20 RC）與召喚工蜂（60 RC）都要花 RC，會隨時間回復。
- **工蜂**：落地後鑽到該欄最底下的空格補洞。
- **旗標炸彈**：HF25 起偶爾出現，落地炸掉周圍 3×3。
- **硬分叉**：從 HF24 開始，每清 10 列升一版，速度加快並隨機換一個時代規則（蜂群時代、RC 緊縮、空投季、鏡像分叉、鯨魚出沒、HBD 升息、區塊加速）。
- **鏈上事件**：每 3 秒出一個區塊，隨機發生鯨魚投票（清掉底列）、反對票（推入垃圾列）、社群空投、出塊失敗（重力暫停）、蜂群補洞、HP 委託、垃圾交易洪水。
- **策展連擊**：連續落子都有清列，獎勵一路疊加。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ / X | 順時針旋轉 |
| Z | 逆時針旋轉 |
| ↓ | 軟降 |
| 空白鍵 | 硬降 |
| C / Shift | 保留 |
| B | 召喚工蜂 |
| P / Esc | 暫停 |
| M | 靜音 |
| L | 開啟語言選單 |

手機會顯示觸控按鈕：左邊是方形的移動鍵（左、右、軟降、硬降），右邊是圓形的旋轉鍵，兩區分開避免按錯。點盤面也可以旋轉。

介面支援 8 種語言：English、Español、Français、繁體中文、简体中文、日本語、한국어、हिन्दी。第一次開啟一律是英文，之後可從首頁右上角、暫停畫面、側欄或觸控列開啟語言選單切換，選擇會記在瀏覽器裡。翻譯集中在 `hive-block-producer/i18n.js`，缺少的字串會退回英文。

# 亂鬥競技場 Brawl Arena

仿《荒野亂鬥》單人荒野決鬥模式的網頁遊戲，單一檔案 `brawl-arena/index.html`，直接用瀏覽器開啟就能玩。重點放在操控方式與場景，角色維持簡單造型。

- **場景**：40×40 格、四向對稱隨機地圖，3/4 俯視角的立體牆、可躲藏的草叢、擋人不擋子彈的水池、能量箱與不可破壞的外牆。
- **規則**：10 名鬥士（你 + 9 個電腦），14 秒後毒霧從四周往中心收縮。打破能量箱或擊倒對手可撿能量方塊，每顆加 400 生命與 10% 傷害。活到最後的人獲勝，依名次增減獎盃。
- **草叢**：站在草叢裡且沒開火時，敵人在 2.3 格外看不到你；開火或受傷會短暫現形。
- **彈藥與回血**：3 格彈藥自動裝填；3 秒沒攻擊也沒受傷就開始回血。
- **大招**：打中敵人累積，集滿後可用，三位鬥士的大招都能破牆。

| 鬥士 | 定位 | 普攻 | 大招 |
| --- | --- | --- | --- |
| 散彈蕾拉 | 散彈槍手 | 5 發扇形散彈 | 9 發散彈，擊退並破牆 |
| 快槍柯特 | 神槍手 | 6 發直線連射 | 12 發長距離連射，打穿牆壁 |
| 鐵拳摔角王 | 重裝坦克 | 4 連拳近戰 | 跳躍重壓，範圍傷害並震碎牆壁 |

## 操作

| 裝置 | 移動 | 普攻 | 大招 |
| --- | --- | --- | --- |
| 手機（建議橫放） | 左半邊任意處拖曳出搖桿 | 右下紅色搖桿：拖曳瞄準、放開射擊；輕點自動瞄準 | 黃色大招鈕：集滿後同樣拖曳或輕點 |
| 電腦 | WASD / 方向鍵 | 按住滑鼠左鍵瞄準、放開射擊；空白鍵自動瞄準 | 滑鼠右鍵；E 自動瞄準 |

遊戲中左上角的「視野」按鈕可切換標準、遠、最遠三段鏡頭距離。獎盃、選擇的鬥士、視野與靜音設定存在瀏覽器的 localStorage。
